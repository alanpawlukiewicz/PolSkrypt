# Przykładowe programy PolSkrypt

Uruchamianie: `PolSkrypt examples/nazwa.pols`

| Plik | Co pokazuje |
|------|-------------|
| [hello_world.pols](hello_world.pols) | najprostszy program |
| [fizzbuzz.pols](fizzbuzz.pols) | pętla `dla`, `jeżeli` / `w_przeciwnym_wypadku`, operator `%` |
| [liczby_pierwsze.pols](liczby_pierwsze.pols) | sito Eratostenesa: listy, pętle zagnieżdżone, funkcje |
| [sortowanie.pols](sortowanie.pols) | sortowanie bąbelkowe i quicksort: rekurencja, listy przekazywane przez referencję, `kopiuj()` |
| [funkcje_wyzszego_rzedu.pols](funkcje_wyzszego_rzedu.pols) | funkcje anonimowe, domknięcia, `mapuj` / `filtruj` / `redukuj`, składanie funkcji |
| [zwierzeta.pols](zwierzeta.pols) | klasy, dziedziczenie, `super`, metody statyczne, polimorfizm, `typ`, `jest_instancją`, `klasa_obiektu` |
| [kalkulator.pols](kalkulator.pols) | program interaktywny: `wprowadź`, `liczba`, pętla zakończona słowem `koniec` |
| [pliki.pols](pliki.pols) | klasa `Plik`: zapis, dopisywanie, odczyt linia po linii, zmiana nazwy, usuwanie |
| [moduly/main.pols](moduly/main.pols) | moduły: `importuj … jako`, `importuj … zsw`, moduły w podkatalogach, nazwy prywatne |

Program `pliki.pols` tworzy pliki tymczasowe w bieżącym katalogu i usuwa je przed zakończeniem.

Dokumentacja języka: [docs/language-reference.md](../docs/language-reference.md).
